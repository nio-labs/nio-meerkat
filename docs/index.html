Nio Meerkat — Self-Healing Local AI Coding Agent & Adaptive Models

Why do local AI coding agents and small models keep repeating the same mistakes? Static weights can't learn after release. Meerkat runs tools, verifies & repairs its own code, remembers what you teach it, and grows ~10–20 MB LoRA coding skills over time.

Nio Meerkat pairs a fast 0.5B Scout (380 MB) with a 1.5B Builder (941 MB) in native Rust via nio-xs, scaling from Tiny Meerkat (16B) at ~250 MB RAM up to Meerkat Ultra (500B).

3. Quickstart

# 1. Install nioxs
curl -fsSL https://raw.githubusercontent.com/nio-labs/nio-xs/main/install.sh | bash

# 2. Pull Meerkat (0.5B + 1.5B) or Tiny Meerkat (2x 135M)
nioxs pull meerkat
nioxs pull tiny-meerkat

# 3. Run locally with --verify, 4-tool loop, or /teach memory
nioxs meerkat "write me a Go while loop"
nioxs meerkat --tools "read Cargo.toml and tell me the package name"
nioxs meerkat teach "our deploy server => 10.0.4.22"
nioxs tiny-meerkat "write a python function to check palindrome"

4. Closed Loop: Detect → Heal → Grow

  • Detect: 0.5B Scout answers casual chat in seconds and routes coding/tool tasks to 1.5B Builder.
  • Heal: Bounded 4-tool XML loop (web_search, web_fetch, read_file, run_python) + --verify multi-round self-repair (--retries).
  • Grow: Episodic memories (meerkat_memory.jsonl) + verified replay traces (meerkat_replay.jsonl) consolidate into ~10–20 MB Wave 1–6 LoRA adapters.
